
# Chapitre 2 — Variables et types de données simples

## Objectif

Comprendre le fonctionnement des variables et apprendre à manipuler des chaînes de caractères en Python.

## Exercices réalisés

**`simple_messages.py`**

Cet exercice consiste à stocker un message dans une variable, à l'afficher avec `print()`, puis à modifier sa valeur pour afficher un nouveau message.

## Notions abordées

- Déclaration et affectation de variables.
- Utilisation des chaînes de caractères (`str`).
- Affichage avec `print()`.
- Réaffectation d'une variable.

## À approfondir

Les méthodes de manipulation des chaînes, les nombres et les premières opérations sur les données.
