# Chapitre 1 — Premiers pas avec Python

## Objectif

Découvrir l'environnement Python et apprendre à écrire et exécuter un premier programme.

## Ce que j'ai appris

- Installer Python sur macOS, Linux et Windows.
- Utiliser l'interpréteur Python depuis le terminal.
- Créer et exécuter un premier script Python.
- Comprendre quelques erreurs courantes et effectuer les premières vérifications pour les résoudre.

## Exercices réalisés

**hello_world.py** — Premier programme utilisant la fonction `print()` pour afficher un message dans le terminal.

## Ce que je retiens

Ce premier chapitre m'a permis de prendre en main Python et de mieux comprendre comment exécuter un programme depuis le terminal.

## Suite de l'apprentissage

Poursuivre avec les variables, les types de données et les premières opérations en Python.
