
# OverTheWire — Bandit

[Bandit](https://overthewire.org/wargames/bandit/) est un wargame d'OverTheWire conçu pour découvrir Linux et les commandes du terminal à travers une série de défis progressifs.

Ce parcours me permet notamment de pratiquer SSH, la navigation dans le système de fichiers, la recherche d'informations et la manipulation des permissions.

## Progression

| Étape | État | Notions |
|---|---|---|
| Niveau 0 | À commencer | Connexion SSH |
| Niveau 0 → 1 | À venir | Navigation et lecture de fichiers |

Le tableau sera mis à jour après chaque étape réalisée.

## Notes techniques

Les notes seront regroupées par sujet plutôt que dans un fichier différent pour chaque niveau.

Sujets prévus :

- Connexion SSH et administration distante.
- Navigation dans le système de fichiers Linux.
- Lecture et recherche de fichiers.
- Permissions et utilisateurs.
- Commandes et outils découverts pendant les challenges.
