
# Systems

Ce dossier regroupe mes notes et exercices d'administration système, principalement autour de Linux, puis de Windows Server et de la virtualisation.

Je travaille notamment avec un serveur physique Dell sous Ubuntu Server 24.04 LTS, accessible à distance par SSH.

## Linux

| Module | Sujet | État |

| 01 | Navigation et gestion des fichiers | Presque terminé |
| 02 | Utilisateurs, groupes et permissions | En cours |
| 03 | Processus, services et systemd | À venir |
| 04 | Réseau et administration à distance | À venir |
| 05 | Shell Bash et traitement de texte | Prévu |
| 06 | Stockage, disques et systèmes de fichiers | À venir |

Les premiers modules portent notamment sur les commandes `pwd`, `cd`, `ls`, `cp`, `mv`, `chmod`, `useradd` et `usermod`.

La partie Bash abordera entre autres `grep`, `awk`, `sed` et `cut`.

**Ressource complémentaire :** *Linux Basics for Hackers*, d'OccupyTheWeb.
