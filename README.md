
# Learning Journey

Ce dépôt rassemble mes notes, exercices et travaux réalisés au fil de mon apprentissage en informatique.

J'y organise les sujets que j'étudie, les exercices que je réalise et les notions que je souhaite approfondir. Le contenu évolue progressivement avec mes cours, mes lectures et mes expérimentations personnelles.

## Domaines d'apprentissage

| Domaine | Contenu | Ressources principales |
|---|---|---|
| [Réseaux](networking/) | Protocoles, modèles réseau, adressage IP, switching, routage et sécurité réseau | Jeremy's IT Lab, Professor Messer |
| [Systèmes](systems/) | Administration Linux, Windows Server, services, utilisateurs, permissions et virtualisation | Linux Basics for Hackers, documentation officielle |
| [Python](python/) | Fondamentaux du langage, exercices, scripts et automatisation | Python Crash Course — Eric Matthes |
| [Cybersécurité](cybersecurity/) | Linux, sécurité offensive et défensive, CTF, wargames et analyse d'incidents | OverTheWire, TryHackMe, Hack The Box, Root-Me, CyberDefenders |

## Exercices et plateformes

En complément de mes cours et de mes lectures, j'utilise différentes plateformes pour mettre en pratique les notions étudiées.

Les exercices réalisés sur OverTheWire, TryHackMe, Hack The Box, Root-Me et d'autres plateformes seront documentés dans le dossier [cybersecurity](cybersecurity/).

Les notes porteront principalement sur les concepts abordés, les outils utilisés et les difficultés rencontrées. Les contenus publiés respecteront les règles de chaque plateforme.
